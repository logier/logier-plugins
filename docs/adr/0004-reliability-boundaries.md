# ADR-0004：可靠性边界（下载、缓存、配置）

- 状态：已采纳（2026-11-21）
- 相关：utils/saved-images.mjs、utils/emoji-thief.mjs、utils/getdate.js、tests/

## 背景

历史 issue 暴露的故障集中在三类：

1. 保存表情包：引用消息里使用未定义变量、空列表直接取 `message[0]`、下载不校验状态/类型/大小、并发编号冲突（#1、I9RCET）。
2. 缓存图片：QQ 图片 rkey 过期后发送 400，缓存里长期保留死链（#3、I9IXPX）。
3. 配置缓存：`getPersonality()` 返回内部数组引用，调用方 `push` 后污染 `personality.json`（#7）。

## 决策

1. 所有图片下载统一走 `utils/saved-images.mjs`：只接受 http(s)、校验状态码与 Content-Type、限制大小与总超时、处理重定向、失败清理残文件、编号加目录锁。
2. 缓存图片发送失败时删除该条并写回，再用图源兜底；读取 Redis 失败时不写回，避免空列表覆盖。
3. 配置读取返回副本；概率类配置统一 clamp 到 0..1，并兼容历史拼写（`Defalut*`/`Default*`）。
4. 失败路径必须有用户可见提示；不允许“提示成功但文件不存在”。

## 后果

- 外部 URL 限制为 http(s) 与常见图片 MIME；本地 `file://` 只用于内部资源。
- 新增命令需复用上述工具，不允许各自实现下载与编号。
- 单元测试覆盖重定向、超限、并发、损坏缓存、过期换图等边界；真实宿主仍需手工回归。
